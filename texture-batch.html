PNG ORM channel packer

Local files / v0.2

Combine ambient occlusion, roughness and metallic maps into one ORM PNG per material. No uploads, accounts or tracking. Processing stays in this page; your original files are never overwritten.

1. Choose your masks

Select the PNGs together from one folder. Each material needs three matching names:

stone_ao.pngstone_roughness.pngstone_metallic.png

  • Material spelling must match exactly.
  • Channel suffixes are case-insensitive.
  • Other filenames are ignored.
  • Keep prior _orm.png outputs out of your selection; they can cause a collision exception.
  • Start with the included synthetic examples if needed.

      Supported PNGs & batch limits

      8-bit, non-interlaced grayscale, RGB, grayscale-alpha and RGBA PNGs. All three maps must have identical dimensions. Input red-channel bytes are used even when alpha is zero. No resizing, colour adjustment or source metadata is carried into the output.

      Palette, 16-bit and animated PNGs and other formats are not supported. Up to 4096 × 4096 and 32 MiB per input PNG; 500 selected files and 256 MiB total compressed input. Encoded PNGs also have a 32 MiB limit, so large noisy images can fail below the dimension limit. Output payload: 120 MiB. Final ZIP: 128 MiB including metadata. Reduce batch size if your browser runs short of memory; these caps are not a memory guarantee.

      Requires native compression streams. Desktop Chrome and Firefox on Linux are tested; no Safari, mobile or game-engine integration is claimed. No folder selection or automatic map-name conversion. Ambiguous or case-colliding names and unsafe ZIP paths are skipped; no missing map is fabricated. Selected files remain in browser memory until the page is closed or replaced.
