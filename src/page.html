      Supported in this experiment

      8-bit, non-interlaced grayscale, RGB, grayscale-alpha and RGBA PNGs, up to 4096 × 4096 and 32 MiB each. Each mask must have the same dimensions. The red input channel is used even when alpha is zero. No resizing, colour adjustment or source metadata is carried into the output.

      Matched files with palette, 16-bit, animated or other unsupported PNG variants are rejected. Nonmatching filenames are ignored. Up to 500 selected files, 256 MiB total compressed input and a 128 MiB output ZIP. Large high-entropy images may exceed the encoder limit. Peak memory use is not yet measured. Requires a recent desktop browser with native compression streams; cross-browser support is not yet established.

      Failed sets are skipped and explained in the ZIP report. A filename-ready set can still fail image validation. No payment or user details are requested.
